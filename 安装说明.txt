简体中文

运行环境
Minecraft Java 1.20.1、Forge 47.4.29、McWW3 2.1-beta。
还需要与当前 McWW3 组合兼容的 Forge 版 Distant Horizons。

安装
1. 退出游戏。从 GitHub Releases 下载 ww3ai-bilingual-tools.jar。
2. 升级时移出当前实例 mods 文件夹里旧的 WW3AI JAR。
3. 把新 JAR 放进该实例的 mods 文件夹，每个实例只放一份。
4. 联机时，客户端和服务器都安装同一份 WW3AI 发布包。
5. 启动游戏，进入世界后按 G。右上角 EN 切到英文，中文切回来。

仓库中的 mods/ww3ai-1.0.0.jar 与 Release 附件
ww3ai-bilingual-tools.jar 是同一个版本，两者选一份安装即可。
游戏内版本号仍显示 1.0.0。

从这里开始
双语玩家手册在 docs/WW3AI-Player-Manual-ZH-EN.pdf。
两种部署器都在创造模式的「工具与实用物品」栏。
G 开控制台，H 切僚机命令，J 开编队编辑。
想开 5v5，按 README 的说明调整 targetPlayersOnly 和 maxVehicles。

English

Requirements
Minecraft Java 1.20.1, Forge 47.4.29 and McWW3 2.1-beta.
Use a Forge build of Distant Horizons compatible with your McWW3 setup.

Install
1. Close the game. Download ww3ai-bilingual-tools.jar from GitHub Releases.
2. Move the old WW3AI JAR out of the instance's mods folder.
3. Put the new JAR in that folder. Keep one copy per instance.
4. For multiplayer, install the same WW3AI release on the client and server.
5. Enter a world and press G. Click EN in the top right for English.
   Click 中文 to switch back. The game remembers your choice.

The repository's mods/ww3ai-1.0.0.jar and the release asset
ww3ai-bilingual-tools.jar have identical contents. Install either one.
The in-game mod version still reads 1.0.0.

Start here
Open docs/WW3AI-Player-Manual-ZH-EN.pdf for the bilingual player manual.
Both deployers are in Creative mode under Tools & Utilities.
G opens the console, H cycles wingman orders, and J opens the formation editor.
For a 5v5, follow the README steps for targetPlayersOnly and maxVehicles.
