01

这是什么

不是脚本回放，是每 tick 读真实姿态与角速度、写输入的闭环控制器。

McWW3 的飞机本身没有像样的无人 AI。这个 Mod 接管场上没有驾驶员的飞机，替它完成一整套空战动作：搜索目标、领先追击、能量管理、失速与触地保护、机炮与导弹开火、被咬尾时脱离。

最有意思的一点是把「怎么飞」和「打谁」彻底分开：

  • 规则层（20 Hz）：只管姿态、速度、高度、开火。不依赖网络，永远不会因为模型超时而失去控制。
  • 模型层（0.5–2 Hz，可选）：只在战局突变时给战术意图。OpenAI 兼容协议与 Ollama 都能接；同一场战斗里红机用模型 A、蓝机用模型 B、僚机用预设脚本，互不干扰。
  • 战后复盘：每局结束把决策记录发回模型，自动微调开火距离、油门、高度偏好，条令跨存档累积。
你坐进驾驶舱时，AI 立刻放手——它只读你的位置和航迹，把你当长机，从不写你的输入。杆量归零但油门保持，同时关掉 ww3 自动驾驶，免得接手瞬间吃到满舵。
02

能做什么，不做什么

边界是设计取舍，不是待办清单。先看清再装，能省掉一半排障时间。

自主空战
目标搜索、领先追击、能量管理、失速 / 触地保护、自动开火
编队配合
你开飞机你就是长机；航迹系梯队站位、全队目标分配不重复
三种战术
按 H 循环 集中火力 / 分散猎杀 / 保护长机；敌方每 5 秒自行判断
战术动作
12 个攻击相位机、高 yo-yo、防御转弯、notch、撤离、三段追踪律
武备与蓝图
按挂架换弹种 / 吊舱，存成全存档共享的蓝图，一键换装
手持部署器
选机型 / 队伍 / 位置，自动算地形高度与航向，成批投放
多模型接入
多渠道多模型，每架飞机独立选大脑，战后自动复盘
可观测性
status / diag / ww3ai-models.log 三层诊断

它不做这些

  • 不改 ww3 本体，不覆盖你的操纵，不放干扰弹（对红外弹只会机动）。
  • 编队是「站位 + 分配」，没有数据链、交叉掩护和撞机规避；一交战就解散。
  • 长机是几何基准，不是指挥官——你没法给二号机下「去看六点」的口令。
  • 控制符号不自动校准：默认 1/−1/−1 只在 f15e 实测过，混编要按机型二分。
  • AGL 是 heightmap 采样不是射线测距，别当精确高度表用。
03

安装

四个依赖，四步确认。版本隔离实例最容易在这一步放错目录。

运行环境 / PREREQUISITES
项要求
Minecraft1.20.1
Forge47.4.29（其它 47.x 大多可用）
ww3必须，2.1-beta
Distant Horizons必须（ww3 的硬依赖）
  1. 把 ww3ai-1.0.0.jar 放进游戏工作目录的 mods/，确认 ww3 与 distanthorizons 也在。用 PCL 等版本隔离实例时，放进该版本自己的 mods 目录。
  2. 启动游戏，主菜单 → Mods 列表能看到「WW3 Air Combat AI」。
  3. 单人存档开启作弊（Esc → 对局域网开放 → 允许作弊），否则 /ww3ai 会被权限拦下；专用服需权限等级 2。
  4. 首次启动会生成 config/ww3ai-common.toml。
[ww3ai] constructed; ww3 present = true
[ww3ai] server starting - AI controller active = true
两个高频坑：① 全局 mods/ 和版本隔离 mods/ 只放一份，放两处会触发 Duplicate mod id；② 换 jar 或改配置后必须完全退出启动器再重开，只重启游戏无效——PCL 缓存版本 json / mod 列表，Forge 也是启动时才加载类与读配置。
04

五分钟上手

从零到看见两架飞机互相咬尾。每一步都带成功判据。

  1. 拿部署器

    /ww3ai deployer

  2. 手持它右键，配四样东西

    机型 f15e；队伍 red（没有就点「新建」→ 填名字 →「建队」）；高度 150 相对地面；把「AI驾驶」点成「开」——这是最常被忘的一步。

    「AI驾驶: 关」是停放模式：飞机放地上、油门归零，AI 不碰它，走过去上机自己开。关着时填 150 的高度也只当「放在地上」。AI 空投最低 120 格离地，低了服务端直接拒绝——实测低空投放会贴地改出、再也拉不起来。

  3. 下一步 → 地图选点 → 投放

    点「下一步」在地图上点位置（或直接填 X/Z），再点「投放（AI 驾驶）」。

    日志出现 took over f15e...，飞机平飞且 5 秒内不掉高度

  4. 按 G 打开控制台，点「生成友机」

    两架开始互相咬尾。也可以在控制台底部一键配置友 / 敌。

  5. 确认战局成立

    /ww3ai status
    tracked=2 且出现 enemy section:
打不起来的头号原因：源码默认 general.targetPlayersOnly=true，只把玩家当目标。想让双方僚机互打，把它改成 false，并在控制台把两队设成敌对——开火需要「有目标 + 敌对关系 + 在射程里」三个条件同时成立。

不想用界面？最快一条：/ww3ai spawn f15e 在你面前的安全点生成并立刻接管，带初速、抬头姿态和满油门；/ww3ai ride 直接坐进刚生成那架。

07

进阶路线

打起来之后，按这个顺序解锁剩下四块能力。

01

带一个小队

自己坐进一架 → /ww3ai assign（不带参数）把附近飞机变成僚机 → 按 H 切三态、按 J 拖队形。敌机进 700 m 时僚机自动脱队交战。

02

换挂载 / 存蓝图

部署器里点机型右侧「武备 / 蓝图」，逐挂点换弹，存成全存档共享的蓝图，/ww3ai blueprints 查看。

03

接大模型

按 G →「模型接入」加渠道（OpenAI 兼容 / Ollama）→ 测试连接 → 拉模型列表 → 在武备页绑模型。看 ww3ai-models.log 的 DECISION。

04

复盘与调参

/ww3ai doctrine 看战后微调的参数。飞机发抖先降 flight.ratePGain（当前默认 0.60），反应迟钝再往回加——一次只改一个。
