## 0. 三十秒确认这是不是你要的东西

**它做这些**

- 接管 ww3 的飞机，以 20 Hz 自己飞：巡航、追瞄、规避、爬升、脱离、开火
- 可选接一个大模型做战术决策（0.5–2 Hz），断网只会让它变笨，不会让飞机掉下来
- 给你一个手持部署器：选机型、选队伍、地图点位置、成批投放
- 按挂架换武器，存成蓝图，同存档一键还原
- 让你的 AI 僚机跟着你飞楔形编队，一个键切换「集中火力 / 分散猎杀 / 保护长机」

**它不做这些**

| 不做 | 原因 |
| --- | --- |
| 改 ww3 本体 | 全程反射调用，无 Mixin、无 Access Transformer |
| 覆盖你的操纵 | 你坐在驾驶舱里，它就是长机，只读你的位置和航迹，从不写你的输入 |
| 释放干扰弹 | AI 对红外弹只会机动，不会放 flare |
| 完整的四机战术 | 编队是"站位 + 目标分配"，没有数据链共享、没有交叉掩护、没有撞机规避 |
| 替你验证倒飞区控制符号 | build134 起 Split-S / 桶滚 / 防御螺旋 / Immelmann / Loop **默认开**，但 `SignTable` 三轴只在正飞验证过；出问题仍需逐轴二分，一次只改一根 |

### 前置

| 项 | 要求 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.4.29（其它 47.x 大多可用） |
| ww3 | 必须，2.1-beta |
| Distant Horizons | 必须（ww3 的硬依赖） |

### 步骤

1. 把 `ww3ai-1.0.0.jar` 放进 `.minecraft/mods/`。
2. 确认 `ww3` 与 `distanthorizons` 也在 `mods/` 里。
3. 启动游戏，主菜单 → Mods 列表能看到「WW3 Air Combat AI」。
4. 单人游戏开启作弊，否则 `/ww3ai` 会被权限拦下。

**确认成功**：进世界后输入 `/ww3ai`，能看到命令帮助列表。

**进服务器**：`/ww3ai` 全部子命令要权限等级 2；菜单里涉及世界状态的按钮默认也要 OP，可用 `general.menuRequireOp=false` 放开。

## 3. 任务：放一架 AI 飞机出去

### 3.1 用部署器（推荐，能选机型、队伍、位置、高度）

1. `/ww3ai deployer` 拿到「空战部署器」。
2. 手持它**右键**，打开界面。
3. 配四个东西：
   - `机型 < >` 选型号，例如 `f15e`
   - `队伍 < >` 选队伍，列表里没有就点 `新建` → 填名字（1–16 字符，可中文）→ `建队`
   - `高度` 填 `150`，右侧按钮切换「相对地面 / 绝对高度」
   - **`AI驾驶` 点成「开」**，这一步最常被忘
4. `下一步 →`，在地图上点一个位置（也可以直接填 X/Z）。
5. 点 `投放（AI 驾驶）`。

**确认成功**

- 日志出现 `took over <机型> at y=.. agl=.. spd=.. signs=roll=1 pitch=-1 yaw=-1 (config)`
- `/ww3ai status` 里 `tracked` 比投放前多 1
- 飞机平飞，5 秒内不往下掉

**关于 `AI驾驶` 开关**

| 状态 | 按钮文字 | 结果 |
| --- | --- | --- |
| 开 | `投放（AI 驾驶）` | 高空投放，AI 立刻接管作战 |
| 关 | `投放（停放自用）` | 放在地面上、油门归零，AI 不碰，走过去上机自己开 |

关着的时候即使填了 150 的高度，也只当"放在地上"。

**AI 驾驶最低 120 格（离地）**。低于这个高度服务端会直接拒绝，并告诉你当前填的是多少：

```
[ww3ai] AI 驾驶空投最低 120 m AGL（当前 60 m）——低于这个高度，飞机一起手就贴地改出、再也拉不起来
```

这不是保守，是实测：空投给的是 70 m/s + 20° 仰角，5 秒内速度掉到 78 m/s，而 60 格正好是强制改出地板。在那个速度上抬头权限只剩 27%，它既爬不上去也退不出改出，会贴着地面翻好几分钟，永远飞不到你身边。要改下限用 `deployer.aiMinClearance`（默认 120，范围 40–280），但**不建议往低调**。

### 3.2 用命令（最快）

```
/ww3ai spawn f15e
```

在你面前的安全点生成并接管，默认 f15e。它会**继承你手持部署器的 AI 选择**——拿着绑了模型的部署器执行，出来的就是模型机。

### 3.3 坐上去自己开（`/ww3ai ride`）

刚放出去的那架已经在天上飞了？不用追：

```
/ww3ai ride
```

传送到**本模组最后生成的那一架**，直接坐进驾驶位。它此时可能已经飞到两千米外、正在做机动，你会被放到座舱里，从那一刻起你来飞。

接手时会发生三件事，都是刻意的：

| 动作 | 为什么 |
| --- | --- |
| AI 立刻放手 | 控制循环跳过所有带乘客的飞机（`takeoverOnlyUnmanned`），下一 tick 起不再有人抢你的杆 |
| 杆量归零、**油门保持** | 免得接手瞬间吃到 AI 当时的满舵（120 格高度上拉一个满杆就是直接扎地）；但油门不清零，否则 70 m/s 的飞机会在几秒内掉到失速 |
| 关掉 ww3 自动驾驶 | 不关的话你一松手它就会接管，和你的操作打架 |

几个边界：

- **那架已经不在了**（被击落、或者你重启过游戏）→ 自动回退到 2000 格内最近的一架，并在消息里说明用的是"最近的"。
- **想主动换一架** → `/ww3ai ride nearest` 跳过记忆，直接坐最近的那架。
- **跳伞之后** → 飞机上的 `ww3ai_ai` 标记还在，AI 会自己接回去继续飞。想彻底交给自己，落地后 `/ww3ai adopt` 别执行、或者用 `/ww3ai dump` 确认它还在 AI 手里再决定。
- **用部署器「停放自用」放的飞机** → 地上停着、油门 0，`ride` 一样能坐进去，但别指望它自己起飞，得你给油门。

控制台（G 键）底部也加了一个「上机」按钮，和这条命令等价。

### 3.3.1 打完了想清场：`clear`

战场上堆了十几架飞机、雷达一片乱的时候，一条命令全清：

- `/ww3ai clear` —— 全地图所有战机，**除了你正驾驶的那一架**（消息里会说"保留 N 架有人驾驶的"）；AI 的控制器、模型会话、目标锁定、编队席位同时清空，`status` 立刻归零。
- `/ww3ai clear all` —— 连自己这架也清。会先把你弹出座舱放回地面，再删飞机，所以不会掉下去摔死。
- `/ww3ai clear vehicles` —— 连坦克、舰船等地面/水面载具一起清。
- `/ww3ai clear <半径>` —— 只清身边这个半径（16–30000 格）内的，远处留着。

控制台（G）底栏的「清场」按钮等价于 `/ww3ai clear`：**第一次点进入待确认态**（按钮变红字 `确认清场`，5 秒不点自动撤销），再点一次才执行——避免清场这种不可撤销的操作被误触。

两个已知边界：只扫**已加载区块**，飞出去几区块外的飞机不在扫描范围；只删实体，不补掉落物、不留残骸。

### 3.4 飞机放出来了但不动

按顺序查这三条：

1. `/ww3ai status` 第二行看 `aircraft=` 和 `untagged=`。
   - `aircraft=0`：压根没搜到飞机（不是接管问题）。
   - `untagged=1`：这架飞机没有 AI 标记，被"只接管已交付的飞机"放过了。
2. 执行 `/ww3ai adopt 300`，把附近无人飞机一次性交给 AI。
3. 还不行就 `/ww3ai dump`，它逐架列出距离、机型、坐标、AGL、速度、乘员数、是否已接管、是否有标记。`status` 只给数量，`dump` 给真相。

> 已经在空中飞的无标记无人机会被自动接管（日志 `adopted airborne <机型>`）；贴地停放的不会被动，所以你自用的那架不会被抢。

## 4. 任务：让它们互相打起来

AI 开火有三个前提：**有目标、是敌对关系、在射程里**。

### 4.1 分阵营

按 `G` 打开控制台：

- 载具列表每行右侧：`敌` / `中` / `友` 设我方队与该队关系；`入队` 把玩家加入该队（成为我方队）
- 底部 `一键配置友/敌` 一步到位
- 底部左侧 `阵营: 敌军` 确认后续新生成的都算敌人
- 右栏显示「我的队伍 / 敌方队伍」：`生成友机` / `/ww3ai spawn` 进我方，`生成敌机` / `prepare` / `/ww3ai hostile` 进敌方
- 最底栏 `生成友机` / `生成敌机` 造几架出来看效果

**确认成功**：`/ww3ai status` 里 `enemy section:` 出现一行，说明敌方机队被识别到了。

### 4.2 关于"只打玩家"

源码默认只把**玩家**当目标。当前实例已经改成双方僚机互打，改回去只需 `general.targetPlayersOnly=true`。

### 4.3 生成点的位置

你的飞机在座舱里时，新生成的飞机会**和你同高**（旧版是地面 +120，你在高空巡航时它出现在脚下一公里）。想做成咬尾开局，把 `[spawn] distance` 调大（如 300）。

## 5. 任务：换挂载、存蓝图

部署器界面 → `武备/蓝图`，标题「WW3 武备与蓝图」。

1. **选挂架**：左栏列出全部挂点，多页时用 `挂点 1/N` + `<页` `页>` 翻。
2. **选弹种**：右栏每行用 `<` `>` 循环。`默认` = 沿用 ww3 原始配置。
3. **选 AI**：左栏 `AI: 预设脚本` 一行，`<` `>` 切换。选项 = `预设脚本` + 所有已启用渠道下的所有模型。
4. **存蓝图**：右下填名字 → `保存`。蓝图存在存档里，同存档的所有部署器共享；同名时按钮变 `确认覆盖`。
5. **应用**：`应用并返回` 写回手持部署器。只想还原挂载用 `恢复默认`。

**确认成功**：重新打开武备页，改动还在；`/ww3ai blueprints` 能列出刚存的蓝图。

> 武备预设只存在物品 NBT 里。切快捷栏导致手上没有部署器时点「应用」会明确报 `请手持部署器`，不会假成功。

## 6. 任务：带一个小队

### 6.1 谁当长机

只要你**坐在一架 ww3 飞机里**，你的飞机就是长机，AI 全部是僚机：

- AI 不碰你的操控，只读你的位置、航迹方向、速度作为队形基准
- 你坐的飞机不会被 AI 接管
- 你的飞机会被标成友军，任何情况下 AI 都不会把它当目标

你下机或改开别的载具，长机自动交回 AI，日志会重新打一次 `section formed`。

没有玩家在飞时，长机是机队里**离你最近**的那架，而且一旦选定就不随距离换人（否则转弯中途换长机会让全队互相穿插）。

#### 谁算僚机：看队伍，不看距离

默认只有**和你同属一个 ww3 队伍**的 AI 飞机才是你的僚机（雷达上青蓝 `OWN` 的点）。盟友队（绿）、中立（白）、没入队的飞机，AI 照样驾驶，但各飞各的，不占 W1/W2 槽位；敌方（红）另组机队。

- 你没入队时，模组**自动把你加入默认队** `blue`（`[teams] playerTeam`），过滤规则照常生效，不再有静默跳过。
- `/ww3ai assign`（**不填队名**）把附近飞机一次性分到你当前所在的队，立刻变僚机；填队名则是分到指定队。某架 `ai=no` 时补一句 `/ww3ai adopt`。
- 控制台「生成友机」和 `/ww3ai spawn` 都生成到你的队；敌机必进敌方队，且两队关系自动设为 `ENEMY`。
- 想回到「所有非敌机都编在一起」：把 `formation.wingmenSameTeamOnly` 设为 `false`。

**排查先看这一行**：`/ww3ai status` 的 `wingmen: team=... sameTeam=N offTeam=N rule=...`。`offTeam>0` 表示有飞机在别的队；`rule=any non-enemy` 只可能是 `wingmenSameTeamOnly=false`，不再由「玩家无队」触发。

### 6.2 僚机站哪：楔形，需要至少两架僚机

槽位定义在长机的**航迹坐标系**里：`前` = 长机速度方向，`右` = 该方向与世界上方的叉积（永远水平），`上` = 右 × 前。

| 僚机 | 相对长机 |
| --- | --- |
| W1 | 左 60 m，后 45 m，低 8 m |
| W2 | 右 60 m，后 45 m，低 8 m |
| W3 / W4 | 上述偏移的 2 倍 |

**为什么你只看到一架在左后方**：W1 编在左、W2 编在右，两架才成 V。只有一架僚机时，右后那个位置是空的。要看到楔形，编队里至少要有 **1 架你的飞机 + 2 架僚机**。

```
section formed: 2 aircraft, leader su33/468255eb (you)     ← 只有 1 架僚机，形不成 V
section formed: 3 aircraft, leader su33/468255eb (you)     ← W1 在左，W2 在右
```

**补齐僚机的办法**：`/ww3ai spawn su33` 生成几架（自动打 AI 标记），或者用部署器放置后 `/ww3ai adopt 300`。

**槽位是座位，不是排队号**：`fm=W1` 这个号只要飞机还在队里就一直保留。以前是每 tick 按 UUID 重排，掉一架后面全部前移一位，而奇数号在左、偶数号在右——于是"补位"变成让僚机从长机右侧横穿 120 m 到左侧。现在新来的拿最小空号，老的不动。

**归队路径**：40 m 内僚机会互相被推开（`formationSeparationBubble`），只推方向不动油门。想让归队的僚机从长机**正后方**汇合而不是从机头前切过去，打开 `formationRejoinCorridor`——它有代价（实测站位误差 41 m → 131 m），只在从 1.5 km 外归队时才划算。

**跟得稳不稳靠油门串级**：位置误差先换成"想要的速度"，再换成油门，而不是直接乘进油门。旧做法在离线仿真里是 290 m 的稳态误差、永远归不了位；现在 41 m、37 秒到位。**"僚机在后面忽快忽慢、始终差两三百米"就是这个环，不要再去调战术参数。**

**判定它到底有没有编入队**：`/ww3ai status` 每架飞机末尾的 `fm=`：

| 值 | 含义 |
| --- | --- |
| `fm=L` | 长机（不站位，飞自由） |
| `fm=W1` / `fm=W2` | 第 1 / 2 号僚机，正在站位 |
| `fm=E1` | 敌方机队的僚机 |
| `fm=-` | 没编队（编队关闭 / 单机 / 你被排除） |

### 6.3 编队什么时候自动解散

**僚机一旦有目标就立刻离开站位去交战。** 站位只在「无目标」时生效——保持队形和打仗是互斥的，被拽回队形的飞机打不了仗。

**第二种情况：它在 `RECOVER` 里。** 改出是安全层，优先级高于一切战术，包括编队。所以当你看到 `fm=W1` 但它人在一两千格外、还贴着地面翻跟头，那不是编队算法坏了——是它压根没飞到能站位的状态。`sinking:` / `diag` 行里 `mode=RECOVER` 且 `agl=0` 就是这条，根因基本都是**空投太低**（见 3.1）。这种飞机救不回来，`/ww3ai spawn` 重新放一架。

脱离交战的半径是 `wingEngageRadius`（默认 700 m，**从你**的位置量）：

| 你想要的 | 改什么 |
| --- | --- |
| 死跟着我，别管远处 | 调到 300 |
| 看见就打 | 调到 3000 或 `0`（不限） |

### 6.4 三种战术：按 `H` 循环

```
分散猎杀 SPLIT  →  保护长机 GUARD  →  集中火力 FOCUS  →  分散猎杀 …
```

动作栏会报当前战术（`[ww3ai] 僚机战术: 集中火力 (focus)`）。状态由服务端保管，掉包、连按、多人同按都不会让显示和实际行为不一致。

不想用按键：`/ww3ai section` 查看，`/ww3ai section focus|split|guard` 直接设。

| 状态 | 目标分配 | 站位 | 什么时候用 |
| --- | --- | --- | --- |
| **FOCUS** 集中火力 | 只留长机正在打的那架，配额放开到全队 | 允许脱离 | 一架硬目标要快速打掉 |
| **SPLIT** 分散猎杀 | 匈牙利全局最优，`maxAttackersPerTarget`(2) 配额 | 各自自由 | 目标数量和我方相当（默认） |
| **GUARD** 保护长机 | 只打威胁长机的（距长机 < 800 m 或接近率 > 50 m/s） | 收紧在长机周边，超 400 m 强制回 | 长机被咬、带人撤退 |

`GUARD` 下僚机离你超过 `guardLeashRadius`(400) 会被强行拉回，`status` 里显示 `leash=OUT`。

**敌方机队自己判断**：每 5 秒评估一次。它长机被咬立刻 `GUARD`；数量不亏且我方还有人 `FOCUS`；数量劣势 `SPLIT`。非紧急切换要连续两次一致才生效，免得在阈值上抖。
调试：`/ww3ai section enemy focus|split|guard` 钉住，`/ww3ai section enemy auto` 恢复。

### 6.5 编队手感调整

| 现象 | 改什么 |
| --- | --- |
| 僚机忽快忽慢、来回摆 | `formationLeadSeconds`：掉队明显加到 0.9，冲过头降到 0.4（默认 0.7） |
| 掉队后绕大圈回来 | 看该机 `mode=` 是不是 `RECOVER`（被地形/失速保护打断）；`formationJoinRange`(600) 内会满油门直追 |
| 你低空飞，僚机每隔几秒爬升离队 | 编队状态地板已降到 `formationFloorAgl`(40)；你贴到 30 m 以下它仍会拉起来，那是保命 |
| 队形太散 | `formationRadius` 75 → 60，`formationRankStep` 75 → 60 |
| 队形太挤 | 两个都往上加，别超过 200 / 200 |
| 队形想更"尖"或更"平" | `formationHalfAngleDeg`：53 是梯队，20 接近纵队，88 接近横队 |
| 不想让僚机比你低 | `formationDroopDeg` 从 6.1 调到 0 |

以上四个数不用记——按 **J** 打开编队编辑器，左边俯视图拖那个琥珀色方块（半径＋半角），右边滑杆调外扩和下沉，侧视图看谁比谁低，按「应用」写盘。预设一键切梯队／楔形／横队／纵队。

## 7. 任务：接一个大模型

不接也能玩，默认就是脚本档。接了之后模型负责"打还是跑"，飞控永远是规则层。

**脚本档和模型档走同一套机动**：防御时的 `BEAM → 反向横滚 → 重新交战` 对两者都生效
（build122 之前脚本档被一个门挡在外面，只会"朝一侧压着坡度"）。

### 7.1 加渠道

按 `G` → `模型接入`。

| 字段 | 填法 |
| --- | --- |
| 协议 | `OpenAI 兼容` 或 `Ollama` |
| Base URL | OpenAI 兼容：`https://api.deepseek.com/v1`、`https://api.moonshot.cn/v1`、中转站、自建网关<br>Ollama：`http://127.0.0.1:11434`（自动补 `/api`）<br>粘完整的 `.../v1/chat/completions` 也行，会自动剥掉重复后缀 |
| API Key | 只写不显。保存后输入框清空，列表只显示 `****abcd`。留空 = 不修改；要删已存的 Key，点右侧 `清Key` → 变 `确认` → 再点一次 |
| 模型 | 点 `拉取模型` 自动列（走 `/models` 或 `/api/tags`），勾选；也可手填 |

`测试连接` 会发一条极短请求并回显耗时。若提示「连接成功但回复无法解析」，说明它只是个聊天模型，换一个指令遵循能力强的。

### 7.2 打开模型层

```
/ww3ai models          # 看渠道与模型层状态
/ww3ai models on       # 关闭状态时打开
```

### 7.3 给飞机绑模型

部署器 → `武备/蓝图` → 左栏 `AI:` 循环到目标模型 → `应用`。

绑定存在实体持久数据里，重启、区块卸载都不丢。同一存档里可以 F-15E 用 DeepSeek、Su-27 用本地模型、僚机用脚本，完全独立。

**确认成功**：投放后 `logs/ww3ai-models.log` 出现 `DECISION jet=... profile=... action=...` 行。

### 7.4 它能看到什么、能选什么

每回合一份 JSON，关键字段：

| 字段 | 含义 |
| --- | --- |
| `bandit.clock` | 1–12 点方位，12 正前、3 正右、6 正后 |
| `bandit.closing` | 接近率，正数 = 距离在缩小 |
| `bandit.tail_aspect` | 0 = 敌机在逃（我们咬尾），180 = 迎头 |
| `threats` | 除当前目标外、1 km 内能打到我们的敌机数 |
| `ctl` | 20 Hz 控制层这一刻在干什么（`mode`/`mv`/`lease`/`ceil`/`vs`/`att`/`bank`） |
| `history` | 最近 4 回合：下了什么指令、哪个机动真的飞了、距离从多少到多少 |

它能选的 7 个动作：`attack`、`extend`、`patrol`、`break_left`、`break_right`、`notch`、`bug_out`，外加 `desired_alt`（高度增量）和 `fire`（开火许可）。

**`fire=true` 只是必要条件**：真扣扳机还要控制器自己判定锥角和距离带。

### 7.5 战后复盘

一场战斗结束后（含活着返航），决策记录会发回同一个模型，让它只调四个数：

```json
{"engage_range": 900, "throttle_bias": -0.05, "altitude_bias": 80,
 "maneuver_bias": 0.08, "note": "lost energy in every merge"}
```

按 `provider/model` 存在 `data/ww3ai_doctrine.dat`，6:4 滑动平均，下一次同模型的飞机起飞就带着新条令。`/ww3ai doctrine` 查看，`/ww3ai doctrine reset` 清零。

**一场交战只复盘一次**：判定要求本场接触目标至少 2 秒，所以纯巡航、或者敌机只在雷达边界闪一下，都不会刷出 `kills=0` 的噪声条令。

## 8. 它现在在干什么：三个地方

| 地方 | 看什么 |
| --- | --- |
| `/ww3ai status` | 一屏看全局：section 摘要、每机一行 |
| `/ww3ai diag true` → `logs/latest.log` | 逐机控制细节，默认每 100 tick（5 秒）一行，可用 `general.logIntervalTicks` 调 |
| `logs/ww3ai-models.log` | 每次模型决策与每条战果 |

### `status` 里最该会读的九个字段

| 字段 | 含义 | 正常值 |
| --- | --- | --- |
| `mode=` | 当前飞行模式 | `PATROL` 巡航、`PURSUE`/`ENGAGE` 进攻、`MANEUVER` 做机动、`BREAK` 防御、`EXTEND` 拉开、`RECOVER` 改出、`LAUNCH` 起飞 |
| `fm=` | 编队站位 | `L` / `W1` / `W2` / `-` |
| `mv=` | 机动与相位 | `-` 或 `yoyo:PULL` 之类 |
| `lk=` | 雷达锁定 | `yes` 才可能打雷达弹 |
| `pur=` | 当前追踪律 | `LEAD` / `PURE` / `LAG` |
| `gear=` | 起落架 | 应长期 `up` |
| `aoa=` | 攻角 / 本机临界攻角 | 稳定在 4–12°，长期贴近临界值（su33 是 **15**）说明攻角顶死，抬头权限正被守卫收走 |
| `g=` | 过载 | 平飞 1.0；急转 5–9；超过本机 `fcsMaxG` 说明 FCS 在限你 |
| `ag=` | 攻角守卫留下的抬头权限 | 巡航 1.00；低速大攻角时 0.3–0.6 是正常的（它在防失速） |
| `los(y/p)` | 机头到目标的视线角 | 落在锥内（机炮 6°、导弹 25°）才可能开火 |
| `lease=` | 包线租约 | `ACT:32` / `COOL` / `-` |

> `err(y/p)` 是**控制误差**（机头到指令方向），不是瞄准误差。判断"为什么不开枪"必须看 `los(y/p)`。

**这三行数字是 build125 才有的。** ww3 一直提供攻角、过载和机体角速度，这个 mod 以前只把攻角写进日志、其余一概不读；现在角速度进了速率环（去掉自加的 1.6 tick 滤波滞后），攻角进了抬头权限的守卫。读不到时全部退回旧算法，不会变成零。

> **build133 修正**：ww3 的 `(right, up, forward)` 是**左手系**，早期把 `rate(p)` / `rate(r)` 的符号接反了，滚转与方向舵速率环一度是正反馈（表现为僚机绕纵轴 ±45° 来回翻滚）。现在两条取数路径共用 `BodyRatesMath`，`rate(p)` 与 `bank` 应同号；`rate(p/q)` 这列才真正可以拿来判故障。

> **build136 起战果直接看 `latest.log`**：击毁瞬间一条 `LOST f15e/72b9bbde ... - releasing AI control`，
> 归属清楚时跟着一条 `KILL jet=su33/… bandit=f15e/… range=403m shots=2 kills=1 cause=SOFT_DEAD hp=0%`。
> 旧版因为 `isAlive()` 对残骸仍为 true，一次 `KILL` 都打不出来，AI 还会对着 `spd=0` 的残骸
> 一直刷 `recovery steady`、每 10 秒白重启一次引擎——现在判死后立即释放控制器和 `maxVehicles` 名额。
> 所有逐机日志都带 `机型/UUID8` 短码，多架同型机不再混成一条流。

## 9. 按症状查

只列最常见的十条。完整表在 [`使用指南.md` 第十三节](使用指南.md)。

| 症状 | 先看 | 处理 |
| --- | --- | --- |
| 飞机放出来往下掉 | 投放高度、`spd` | 确认 `[spawn] launchAssist` 为 `true`（默认开）；初速提到 90；高度提到 200 |
| 飞机不动、不接管 | `status` 第二行 `aircraft=` / `untagged=` | `/ww3ai adopt 300`；或 `/ww3ai dump` 逐架看 |
| 它永远只有 75 m/s | `diag` 的 `gear=` | 应自动收起（日志 `gear up (was down at takeover)`）。仍是 `DOWN` 说明停在地面，属正常 |
| 我开飞机，僚机不跟 | `status` 第一行有没有 `(you)`；各机 `fm=` | 玩家在座舱即长机，无条件、无开关（`playerLeads` 已删）；僚机在交战或 `RECOVER`（`mode` 不是 `PATROL`）属正常 |
| 有 `fm=W1` 但它贴地翻跟头、离你一两千格 | `mode=`、`agl=`、`y=` | 它在 `RECOVER` 里，站位不会执行。若 `agl=0` 而 `y` 很高（如 300），是**假 AGL=0**（build130 及以前的高度算法缺陷）；build131 已修，升级 jar 后重进世界。若 `agl` 随 `y` 正常变化而仍然贴地，才是真低空，用 `/ww3ai clear` + 部署器重新在 ≥120 格投放 |
| 飞机刚出生就一直 `RECOVER`，几十秒不脱出 | 日志 `AGL disagrees with terrain` / `recovery fuse tripped` | 前者说明几何纠正已生效；后者是 `recoverFuseTicks`(200) 兜底解锁。两者都出现说明还有别的高度源在骗，开 `/ww3ai diag` 看 `agl` 与 `y` 的差 |

| 保险丝反复触发、十几秒一轮 RECOVER，速度一直 70–85 | `recover: ENTER/EXIT mask=`、`recovery steady:` | build135 已修退出死锁：`recoverExitBand`(30) 加滞回、`pullUpDebounceTicks`(3) 去抖、`escapeClimbTicks`(120) 给保险丝后一次有界浅爬升；退出判据 `recoveryExit()` **不要求速度恢复**。回归 `tools/sim.sh run S12` |
| 只有一架僚机、没有楔形 | `section formed: N aircraft` | 补到 3 架：`/ww3ai spawn`（默认进我方队）或部署器 + `adopt` |
| 飞机在旁边却不站 W1/W2 | `status` 的 `wingmen:` 行 | `offTeam>0` → `/ww3ai assign`（不带参数）分到你的队；`rule=any non-enemy` → 把 `wingmenSameTeamOnly` 改回 `true` |
| 僚机全散了不跟 | `wingEngageRadius` | 调小到 300 |
| 整场不发导弹 | `los(y/p)`、`lk=`、`ammo` | `los` 超锥 = 机头没指过去；在锥内但 `ammo` 不减 = 不在射程带或 `allowFire` 为假 |
| 导弹一下全射出来 | `missile away` 日志的 `ammo a -> b` | `b = a-1` 正常；掉 2 以上是该组双联装，属挂载问题 |
| 咬住尾就左右翻、还不了手 | `aoa=`、`spd`、`bank=`、`rate(p)=` | ① `spd` ≤ 84 且 `gear=down` → 先收轮，放轮时极速只有 81 m/s；② `aoa` 持续 >15° → 降 `cornerSpeedFrac` 到 0.78–0.80；③ **`bank` 在 ±45° 来回且 `rate(p)` 与 `bank` 变化反号 → 角速度符号 bug，build133 已修，升级 jar 重进世界即可**（旧结论归给「方向舵饱和/侧滑耦合」是表象）。方向舵能力的封顶（build122）仍在，但只压幅度 |
| 飞机发抖、杆来回摆 | `diag` 的 `cmd` 每 tick 正负跳，以及 `rate(p)` 与 `bank` 是否同号 | 先判符号：不同号 = build133 的角速度 bug（升级 jar）；同号才是增益问题。**build138 起 `ratePGain` 默认已是 0.60**（WARN 会打印当前值可核对）；仍抖再试 0.5，或把 `rateSlewMaxPerSec` 降到 2.0 |
| 僚机一直绕纵轴像桶滚一样左右翻（±45°） | `rate(p)` 与 `bank=`、`mode=RECOVER` 占比 | build133 已修（`BodyRatesMath` + S11 回归）。不要翻 `ROLL_SIGN`，也不要靠 `useWw3BodyRates=false` 绕开——signs 只改输出杆量，旧差分估计同样接反 |
| 拉起时直接扎地 | 控制符号 | **逐轴二分**，一次只翻一根。默认 f15e = `1 -1 -1` |
| 直升机/非 f15e 机型杆量明显不对 | 日志有没有 WARN `control authority: ...(fallback)` | build126 起兜底值会每 5 秒自动重读，成功时打 `control authority re-read:`；一直没有 re-read 说明那架实体从未被 tick（如模拟距离外生成），飞近让它加载即可 |

### 控制符号：绝对不要三轴一起翻

| 现象 | 翻哪根 | 命令 |
| --- | --- | --- |
| 一路滚到倒扣 | roll | `/ww3ai signs -1 -1 -1` |
| 不倒扣了，但改出时越拉越低、直接扎地 | pitch | `/ww3ai signs 1 1 -1` |
| 转弯侧滑、掉高度但不翻 | yaw | `/ww3ai signs 1 -1 1` |

定下来后按机型存盘：`/ww3ai signs <r> <p> <y> <机型ID>`，写在 `config/ww3ai-signs.properties`，独立于 toml，不会被游戏退出时回写覆盖。

`signs 1 1 1` 会修好 roll 同时弄坏 pitch，从"倒扣"变成"俯冲"，看起来像换了个 bug。

## 11. 它做不到什么

| 边界 | 说明 |
| --- | --- |
| 编队不是完整四机战术 | 没有数据链（每架用自己的雷达）、没有交叉掩护、没有撞机规避 |
| 站位只在无目标时生效 | 一交战就解散——保持队形和打仗互斥 |
| 长机是几何基准，不是指挥官 | 你没法说"二号去看六点" |
| AI 不放干扰弹 | 对红外弹只会机动；你打它时 flare 照样能骗掉它的弹 |
| 低空基本只能靠导弹 | `attackFloorAgl` 让它在 150 m 平飞通过，机炮 6° 锥基本覆盖不到下方目标 |
| 攻击地板 105 m 是"能打"，不是"不会撞" | `recoverSeconds` 按当前下沉率线性外推，陡俯冲或倒扣时仍然偏乐观 |
| 击杀判定看 ww3 生命状态 | build136 起用 `health.isDead()`（SOFT_DEAD / HARD_DEAD）判死并立刻释放控制器，`latest.log` 打 `LOST` 与 `KILL`；目标若在发现前就被移除仍可能漏记 |
| `cruiseSpeed=130` 高于物理极速 | ww3 阻力随 v² 增长、推力恒定；su33 收轮约 102 m/s、F-15 约 90–96 m/s。**build137 已解耦**：油门目标改用 `trimSpeed=80`，`cruiseSpeed` 保留 130 只作保护阈值参考尺；单独调低它会让改出门槛(→44)失效、并在低速恒给 24° 强爬升 |
| 控制符号不会自动校准 | 默认 `1/-1/-1` 只在 f15e 实测过，其它机型要人二分 |
| 蓝图与条令都是存档级 | 换存档不共享 |
