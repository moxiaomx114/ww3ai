> 规则层每秒 20 次管杆舵，可选的大模型每秒 0.5–2 次只管战术——**模型永远不碰操纵面，断网最多让飞机变笨，不会让它掉下来**。

## 01 这是什么

McWW3 的飞机本身没有像样的无人 AI。这个 Mod 接管场上**没有驾驶员**的飞机，替它完成一整套空战动作：搜索目标、领先追击、能量管理、失速与触地保护、机炮与导弹开火、被咬尾时脱离。它不是脚本回放，而是每 tick 读真实姿态与角速度、写 `VehicleInputHandler` 的闭环控制器。

最有意思的一点是**把「怎么飞」和「打谁」彻底分开**：

- **规则层（20 Hz）**：只管姿态、速度、高度、开火。不依赖网络，永远不会因为模型超时而失去控制。
- **模型层（0.5–2 Hz，可选）**：只在战局突变时给战术意图（集中 / 分散 / 保护、追谁、什么时候脱离）。OpenAI 兼容协议与 Ollama 都能接，同一场战斗里红机用模型 A、蓝机用模型 B、僚机用预设脚本，互不干扰。
- 打完一局还会把决策记录发回模型做**战后复盘**，自动微调开火距离、油门、高度偏好，条令跨存档累积。

你坐进驾驶舱时，AI 立刻放手——它只读你的位置和航迹，把你当长机，从不写你的输入。

## 02 能做什么 / 不做什么

**能做的**

| 能力 | 说明 |
| --- | --- |
| 自主空战 | 目标搜索、领先追击、能量管理、失速 / 触地保护、自动开火 |
| 编队配合 | 你开飞机你就是长机；航迹系梯队站位、全队目标分配（谁打谁不重复） |
| 三种战术 | 按 `H` 循环「集中火力 / 分散猎杀 / 保护长机」；敌方机队每 5 秒自行判断用哪一态 |
| 战术动作 | 12 个攻击相位机、高 yo-yo、防御转弯、notch、撤离、三段追踪律 |
| 武备与蓝图 | 按挂架换弹种 / 吊舱，存成全存档共享的蓝图，一键换装 |
| 手持部署器 | 选机型、选队伍、地图点位置，自动算地形高度与航向，成批投放 |
| 多模型接入 | 多渠道多模型，每架飞机独立选大脑；战后自动复盘 |
| 可观测性 | `/ww3ai status`、`diag`、`logs/ww3ai-models.log` 三层诊断 |

**不做的**（这些是设计边界，不是待办清单）

- 不改 ww3 本体，不覆盖你的操纵，不放干扰弹（AI 对红外弹只会机动，不会放 flare）。
- 编队是「站位 + 目标分配」，没有数据链、没有交叉掩护、没有撞机规避；一交战队形就解散。
- 长机是几何基准，不是指挥官——你没法给二号机下「去看六点」这种口令。
- 控制符号不是自动校准的：默认 `1/−1/−1` 只在 f15e 上实测过，混编机型要靠 `/ww3ai signs` 按机型二分。
- AGL 是 heightmap 采样不是射线测距，别把它当精确高度表用。

## 03 安装

**前置**：Minecraft 1.20.1、Forge 47.4.29、ww3 2.1-beta、Distant Horizons。

1. 把 `ww3ai-1.0.0.jar` 放进游戏工作目录的 `mods/`，确认 `ww3` 与 `distanthorizons` 也在。
   > 用 PCL 等启动器的**版本隔离**实例时，放进该版本自己的 `mods/`（例如 `versions/1.20.1-forge-47.4.29/mods/`）。**只放一份**——同时放全局 `mods/` 会触发 `Duplicate mod id`。
2. 启动游戏，主菜单 → Mods 列表能看到「WW3 Air Combat AI」。
3. 单人存档请**开启作弊**（Esc → 对局域网开放 → 允许作弊），否则 `/ww3ai` 会被权限拦下。专用服需权限等级 2（OP）。
4. 首次启动会生成 `config/ww3ai-common.toml`。

**确认成功**：进世界后输入 `/ww3ai` 能看到命令帮助；日志里有
```
[ww3ai] constructed; ww3 present = true
[ww3ai] server starting - AI controller active = true
```

> ⚠️ **更新 jar 或改配置后，必须完全退出启动器再重开**。只重启游戏无效，PCL 会缓存版本 json 和 mod 列表，Forge 也是启动时才加载类。

## 04 五分钟上手：从零到看见两架飞机打起来

**① 拿部署器**

```
/ww3ai deployer
```

**② 手持它右键**，打开两页界面。

**③ 配四样东西**（第一页）

| 项 | 填什么 |
| --- | --- |
| 机型 | `f15e` |
| 队伍 | `red`（列表里没有就点「新建」→ 填名字 →「建队」） |
| 高度 | `150`，相对地面 |
| **AI驾驶** | **点成「开」** ← 最常被忘的一步 |

> 「AI驾驶: 关」是停放模式：飞机放在地上、油门归零，AI 不碰它，走过去上机自己开。关着时填 150 的高度也只当「放在地上」。
> AI 空投**最低 120 格离地**，低了服务端会直接拒绝并提示当前值——这是实测出来的：低空投放会贴地改出、再也拉不起来。

**④ 点「下一步」**，在地图上点一个位置（也可直接填 X/Z）。

**⑤ 点「投放（AI 驾驶）」**。日志出现 `took over f15e ...`，飞机平飞且 5 秒内不掉高度。

**⑥ 按 `G` 打开控制台 → 点「生成友机」**，两架开始互相咬尾。

**⑦ 确认**

```
/ww3ai status
```

看到 `tracked=2` 说明两架都被接管；出现 `enemy section:` 说明敌方机队已被识别。

> **打不起来的头号原因**：源码默认 `general.targetPlayersOnly=true`，只把玩家当目标。想让双方僚机互打，把该项改成 `false`，并按 `G` 在控制台把两队设成敌对——`canEngage` 要「有目标 + 敌对关系 + 在射程里」三个条件同时成立。

**不想用界面？** 最快就一条：

```
/ww3ai spawn f15e
```

在你面前的安全点生成并立刻接管，带初速度、抬头姿态和满油门。想自己飞就 `/ww3ai ride` 直接坐进刚生成那架。

## 05 三个入口

| 入口 | 打开方式 | 适合 |
| --- | --- | --- |
| 控制台 | 按 `G` / `/ww3ai menu` | 分阵营、生成友敌机、改队形、配模型渠道 |
| 手持部署器 | `/ww3ai deployer` → 右键 | 选机型 / 队伍 / 位置 / 高度，成批投放，改挂载存蓝图 |
| 命令 | `/ww3ai ...` | 最快、可写进命令方块、批量排查 |

按键：`G` 控制台、`H` 循环僚机战术、`J` 编队队形编辑器（可在「选项 → 控制」改绑）。

## 06 常用命令速查

| 命令 | 作用 |
| --- | --- |
| `/ww3ai` | 帮助 |
| `/ww3ai status` | 总览 + 每机一行（最常用） |
| `/ww3ai dump [半径]` | 逐架列出距离、机型、坐标、AGL、速度、是否已接管 |
| `/ww3ai spawn [机型]` | 面前生成并接管，默认 f15e |
| `/ww3ai ride [nearest]` | 坐进最后生成的那架 / 最近的一架 |
| `/ww3ai adopt [半径]` | 把附近无人飞机交给 AI（默认 300 格） |
| `/ww3ai clear [all\|vehicles\|<半径>]` | 一键清场，默认保留你驾驶的那架 |
| `/ww3ai deployer` | 拿部署器 |
| `/ww3ai prepare` | 一键配好两队 + 玩家入我方 + 附近飞机进敌方 + 关系敌对 |
| `/ww3ai relation <队> <enemy\|neutral\|ally>` | 设两队关系 |
| `/ww3ai assign [队]` | 附近载具批量入队；省略队名 = 全变你的僚机 |
| `/ww3ai section` | 看友 / 敌战术与敌机架数 |
| `/ww3ai section focus\|split\|guard` | 钉住友军战术 |
| `/ww3ai on` / `off` | 运行时开关 AI |
| `/ww3ai diag <true\|false>` | 逐机详细诊断日志 |
| `/ww3ai models` / `blueprints` / `teams` | 列模型渠道 / 蓝图 / 队伍 |
| `/ww3ai signs` | 列控制符号与按机型覆写 |

完整 30 余条命令见 [`使用说明书.md`](使用说明书.md) 附录 A。

## 07 进阶路线

1. **带一个小队**：自己坐进一架 → `/ww3ai assign`（不带参数）把附近飞机变成僚机 → 按 `H` 切三态、按 `J` 拖队形。敌机进 700 m 时僚机自动脱队交战。
2. **换挂载 / 存蓝图**：部署器里点机型右侧「武备 / 蓝图」，逐挂点换弹，存成全存档共享的蓝图。`/ww3ai blueprints` 查看。
3. **接大模型**：按 `G` →「模型接入」加渠道（OpenAI 兼容 / Ollama）→ 测试连接 → 拉模型列表 → 在武备页给飞机绑模型。看 `logs/ww3ai-models.log` 里的 `DECISION`。模型层总开关 `/ww3ai models on|off`。
4. **复盘与条令**：`/ww3ai doctrine` 看战后自动微调的参数，`/ww3ai doctrine reset` 清空。
5. **调参**：`config/ww3ai-common.toml`。飞机发抖先降 `flight.ratePGain`（当前默认 `0.60`），反应迟钝再往回加；**一次只改一个**。

## 08 排障：最常见的五个坑

| 症状 | 先查 |
| --- | --- |
| 投放后飞机停在地上不动 | 部署器的 `AI驾驶` 没打开（关 = 停放自用） |
| 两架飞机互相无视 | `general.targetPlayersOnly` 是不是 `true`；两队关系是不是敌对（`/ww3ai teams`） |
| 飞机放出来了但 AI 不接管 | `/ww3ai status` 看 `aircraft=` / `untagged=`，再 `/ww3ai adopt 300`，还不行用 `/ww3ai dump` 看真相 |
| 换了 jar / 改了配置却没变化 | 没有**完全退出启动器**再重开；Forge 只在启动时加载类和读配置 |
| 高度填 60 被拒绝 | AI 空投下限 120 m AGL，这是防贴地改出的硬门槛，不建议调低 |

更完整的按症状排查见 [`使用说明书.md`](使用说明书.md) 第 9 章；原理、阈值来源与设计取舍见 [`使用指南.md`](使用指南.md)。
